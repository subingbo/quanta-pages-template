# 经典浅色（classic）

白底、深灰文字、橙色强调，圆角卡片和双列文章网格。是最早的官方模板，适合技术笔记、项目记录和日常随笔。

- 发布目录：`/templates/classic`
- 主色：`#f97316`
- 字体：系统无衬线（PingFang SC / Microsoft YaHei）
- 特点：浅色、卡片、双列首页、圆角头像

本目录的 `index.html`、`blog.html`、`article.html`、`about.html`、`assets/site-core.*`、`assets/app.js`、`vendor/markdown-it.min.js` 由 `npm run sync` 从 `shared/` 生成；只修改 `assets/styles.css` 和 `favicon.svg`。
